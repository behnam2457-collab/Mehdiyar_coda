# راه‌اندازی مهدیار روی Render

این بسته شامل فایل اصلی سرور و فایل تنظیمات نصب است. داشبورد HTML داخل `server.py` قرار دارد و فایل جداگانه‌ای لازم نیست.

## مرحله ۱: بارگذاری در GitHub

1. مخزن خصوصی `Mahdyar` را در GitHub باز کن.
2. روی **Add file** و بعد **Upload files** بزن.
3. دو فایل `server.py` و `requirements.txt` را انتخاب و بارگذاری کن.
4. پایین صفحه روی **Commit changes** بزن.

## مرحله ۲: ساخت سرویس در Render

1. وارد https://render.com شو و با GitHub وارد شو.
2. از داشبورد Render گزینه **New** و سپس **Web Service** را انتخاب کن.
3. مخزن `Mahdyar` را وصل کن.
4. تنظیمات را این‌طور قرار بده:
   - **Runtime:** Python
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
   - **Instance Type:** Free (اگر در حساب/منطقه‌ات نمایش داده شد)
5. روی **Create Web Service** بزن و منتظر پایان Deploy بمان.

## مرحله ۳: آزمایش

بعد از Deploy، آدرس سرویس را از Render بردار و این مسیر را در مرورگر باز کن:

`https://آدرس-سرویس.onrender.com/api/health`

اگر پاسخ وضعیت سالم سرور را دیدی، مسیر `/` را هم باز کن تا داشبورد نمایش داده شود.

## نکته مهم

این تغییر فقط پورت را با متغیر محیطی Render سازگار می‌کند. هنوز اتصال واقعی Render به کدال و استخراج گزارش‌ها روی سرور آنلاین آزمایش نشده است؛ این کار بعد از Deploy انجام می‌شود. در پلن رایگان ممکن است سرویس پس از مدتی بی‌درخواستی به خواب برود و اولین بازدید بعدی با تأخیر باز شود.
